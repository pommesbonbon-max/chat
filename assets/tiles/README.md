# Atlas: состав тайлов

Источник: [Flamm64/GTA-V-World-Map](https://github.com/Flamm64/GTA-V-World-Map), коммит `2f2f85a680e650fd4e141abfdda1e8df7158eb13`, архив `Atlas/Atlas.7z`.

Включён поднабор уровней `0–5`: 1365 JPG-файлов `256 × 256`, `21 069 637` байт. Имена исходного архива `{z}_{x}_{y}.jpg` преобразованы в структуру `atlas/{z}/{x}/{y}.jpg`; сами изображения не изменялись.

| Уровень | Столбцы и строки | Число тайлов |
| --- | --- | --- |
| 0 | `0` | 1 |
| 1 | `0–1` | 4 |
| 2 | `0–3` | 16 |
| 3 | `0–7` | 64 |
| 4 | `0–15` | 256 |
| 5 | `0–31` | 1024 |

Полотно уровня `5` — `8192 × 8192`. Уровни `6–7` исходного архива и отдельный `empty.jpg` не включены. Atlas — единственный поставляемый стиль на этапе 3.

Автор карты — Zslash / Martin Floden. Исходный notice, контрольная сумма архива и сведения о геопривязке сохранены в [docs/sources.md](../../docs/sources.md). Геопривязка основана на общественной калибровке; точность 1:1 независимо не подтверждена.
