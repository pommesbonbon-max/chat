# Atlas / Satellite / Roadmap: состав тайлов

Источник: [Flamm64/GTA-V-World-Map](https://github.com/Flamm64/GTA-V-World-Map), коммит `2f2f85a680e650fd4e141abfdda1e8df7158eb13`, архивы `Atlas/Atlas.7z`, `Satellite/Satellite.7z` и `Roadmap/Roadmap.7z`.

Для каждого стиля включены уровни `0–5`: по 1365 JPG-файлов `256 × 256`, всего 4095 файлов. Имена исходного архива `{z}_{x}_{y}.jpg` преобразованы в структуру `{atlas|satellite|roadmap}/{z}/{x}/{y}.jpg`; сами изображения не изменялись.

| Satellite | 1365 | 25 646 220 |

| Всего | 4095 | 68 759 825 |

Число тайлов на каждом уровне одного стиля:

| Уровень | Столбцы и строки | Число тайлов |
| --- | --- | --- |
| 0 | `0` | 1 |
| 1 | `0–1` | 4 |
| 2 | `0–3` | 16 |
| 3 | `0–7` | 64 |
| 4 | `0–15` | 256 |
| 5 | `0–31` | 1024 |

Полотно уровня `5` — `8192 × 8192`. Уровни `6–7` исходных архивов и отдельные пустые изображения не включены. Все три подложки используют общую сетку XYZ и игровую проекцию; переключение стиля сохраняет положение объектов.
