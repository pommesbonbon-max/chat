# GTA V Map — этап 3

Статическое приложение на HTML/CSS/JavaScript и Leaflet 1.9.4. Карта Los Santos и Blaine County открывается на настоящей подложке **Atlas** из проекта [Flamm64/GTA-V-World-Map](https://github.com/Flamm64/GTA-V-World-Map). Работают навигация, масштабирование, ограничение области и локальная загрузка тайлов.

В поставку включены уровни `0–5`: 1365 JPG-тайлов размером `256 × 256`, около 21 МБ. На максимальном поставляемом уровне полотно имеет размер `8192 × 8192` пикселя. Это выбранная часть исходной пирамиды `0–7`, а не утверждение о максимальном разрешении оригинальной карты.

**Игровые координаты привязаны по общественной калибровке; точность 1:1 независимо не подтверждена.** Коэффициенты взяты из [oyuh/w3w-map](https://github.com/oyuh/w3w-map/blob/master/src/lib/w3w.ts), использующего тот же набор тайлов. Игровые границы рассчитаны из этой привязки и охватывают всё квадратное полотно, включая океан. Формулы и ограничения приведены в [docs/projection.md](docs/projection.md).

## Локальный запуск

Нужен Python 3. Откройте терминал в каталоге проекта:

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

Затем откройте <http://127.0.0.1:8080>. Если установлен Node.js 18+ с npm, тот же сервер запускается командой `npm run serve`. Установка npm-зависимостей не требуется. Для JavaScript-модулей используйте HTTP-сервер, а не открытие `index.html` через `file://`.

Проверка математики и конфигурации:

```sh
npm test
```

Leaflet поставляется локально в `assets/vendor/leaflet/`. Atlas загружается из `assets/tiles/atlas/`; внешние картографические сервисы для запуска не требуются.

## Конфигурация

В `js/config.js` находятся `MAP_CONFIG.worldBounds`, размеры и смещения `raster`, размер тайла, доступные масштабы и данные слоя. Стандартный режим — `tileMode: 'xyz'`; путь Atlas — `./assets/tiles/atlas/{z}/{x}/{y}.jpg`. `calibration: 'community'` обозначает источник калибровки и не является подтверждением её точности.

Для проверки геометрии можно выбрать `MAP_CONFIG.tileMode = 'diagnostic'`. Этот режим рисует координатную сетку и не подменяет отсутствующие файлы карты. Для возврата к Atlas установите `'xyz'`.

При замене подложки согласуйте `worldBounds`, `raster`, `nativeZoom` и доступные уровни с новым исходником. `raster.width/height` задают размер полезного изображения, `raster.offsetX/offsetY` — его поля внутри тайлового полотна на родном уровне. Проверяйте независимые контрольные точки в центре и по краям. Одинаковое число тайлов само по себе не подтверждает одинаковую геопривязку.

Автор исходной карты — Zslash / Martin Floden. Источник тайлов зафиксирован на коммите `2f2f85a680e650fd4e141abfdda1e8df7158eb13`. Точный исходный notice и сведения о происхождении сохранены в [docs/sources.md](docs/sources.md); состав поднабора — в [assets/tiles/README.md](assets/tiles/README.md).

Проект не требует сборки и может обслуживаться обычным статическим сервером. Относительные пути ресурсов позволяют подготовить размещение в подпапке GitHub Pages. Публикация, настройка GitHub Pages, коммиты и push не выполняются автоматически.

Большие исходные растры и временные файлы нарезки исключены из Git. Объёмные наборы тайлов можно хранить отдельно и подключать через конфигурацию. Не помещайте ключи доступа к закрытым сервисам в клиентский JavaScript.
