# GTA V Map — этап 4

Статическое приложение на HTML/CSS/JavaScript и Leaflet 1.9.4: карта Los Santos и Blaine County с переключением **Atlas / Satellite / Roadmap**, поиском мест и игровых координат, пользовательскими метками.

Все три подложки включены локально: уровни `0–5`, по 1365 JPG-тайлов `256 × 256`; всего 4095 файлов, около 68.8 МБ. Полотно каждого стиля на уровне `5` имеет размер `8192 × 8192`. Это выбранная часть исходных пирамид, а не максимальное разрешение оригинальных карт.

**Игровые координаты привязаны по общественной калибровке; точность 1:1 независимо не подтверждена.** Коэффициенты взяты из [oyuh/w3w-map](https://github.com/oyuh/w3w-map/blob/master/src/lib/w3w.ts), использующего тот же набор тайлов. Игровые границы рассчитаны из этой привязки и охватывают всё квадратное полотно, включая океан. Формулы и ограничения приведены в [docs/projection.md](docs/projection.md).

## Локальный запуск

Нужен Python 3. Откройте терминал в каталоге проекта:

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

Затем откройте <http://127.0.0.1:8080>. Если установлен Node.js 18+ с npm, тот же сервер запускается командой `npm run serve`. Установка npm-зависимостей не требуется. Для JavaScript-модулей используйте HTTP-сервер, а не открытие `index.html` через `file://`.

Проверки проекта:

```sh
npm test
```

Leaflet, тайлы и каталог мест включены в проект; внешние картографические сервисы для запуска не требуются.

## Использование

- Выберите Atlas, Satellite или Roadmap. Все стили используют одну систему координат; при переключении сохраняются масштаб, положение и метки.
- В поле «Место или X, Y» введите название из локального каталога либо игровые координаты, например `100, -200`. Координаты должны быть конечными числами внутри границ карты. Каталог содержит 34 выбранные точки из конфигураций FiveM с русскими и английскими поисковыми названиями; это не полный справочник адресов и объектов GTA V.
- Нажмите «Добавить метку», задайте название, координаты и значок: Точка, Звезда или Флаг. «Выбрать на карте» позволяет указать положение следующим кликом.
- В списке «Мои метки» можно показать, изменить или удалить метку; перетаскивание меняет её координаты.
- Переключатели «Известные места», «Мои метки» и «Координатная сетка» управляют отображением соответствующих объектов.

Пользовательские метки сохраняются в `localStorage` текущего браузера для текущего адреса сайта. Они остаются после перезагрузки страницы, пока хранилище доступно и не очищено. Серверного хранения и синхронизации между браузерами или устройствами нет; другой адрес или порт использует отдельное хранилище.

## Данные и конфигурация

В `js/config.js` находятся игровые границы, геометрия растра, масштабы и параметры трёх слоёв. Тайлы расположены в `assets/tiles/{atlas|satellite|roadmap}/{z}/{x}/{y}.jpg`. При замене источника необходимо заново проверить геопривязку; одинаковое число тайлов само по себе её не подтверждает.

Большие исходные растры и временные файлы нарезки исключены из Git. Объёмные наборы тайлов можно хранить отдельно и подключать через конфигурацию. Не помещайте ключи доступа к закрытым сервисам в клиентский JavaScript.
